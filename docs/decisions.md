# 결정 기록

팀이 정한 것과 그 이유입니다. 바꾸고 싶으면 먼저 팀과 이야기하고, 바뀌면 여기도 고칩니다.

- **폴더 구조는 `app` / `features` / `shared`** — 기능 단위로 코드를 모으고, 공용 코드는 `shared`로 분리
- **라우터는 브라우저 라우터 (해시 라우터 X)** — Capacitor 앱에서도 동작하고 딥링크 URL이 깔끔함
- **Squash 머지만 사용** — PR 제목이 그대로 `main`의 커밋 메시지가 되어 기록이 깔끔함
- **커밋·PR 제목은 `{타입}: {설명}`, CI로 검사** — 나중에 release-please가 이 메시지로 버전과 변경 기록을 만듦
- **`feat`·`fix`만 이슈 필수** — 기능·버그는 추적하고, 사소한 작업은 바로 PR
- **pnpm 사용, Node·pnpm 버전은 패치까지 고정** — 모두 같은 환경에서 작업하고, 업데이트가 나와도 자동으로 올라가지 않게
- **의존성은 `^`·`~` 없이 정확한 버전만** — 설치할 때마다 버전이 달라지지 않게
- **CODEOWNERS는 버전·CI·설정 파일만 보호** — 라이브러리 추가는 자유롭게, 버전 고정 여부는 CI가 검사
- **일반 PR은 CodeRabbit 승인으로 머지** — 설정 파일이 바뀐 PR만 담당자 승인 필요
- **AI 규칙은 `AGENTS.md` 한 곳에** — Claude Code와 Codex가 같은 규칙을 읽음
- **화면 개발 전에 디자인 시스템과 공용 컴포넌트부터** — 화면마다 색·크기·컴포넌트가 제각각이 되는 것을 막음
