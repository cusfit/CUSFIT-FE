## 작업 순서

1. **디자인 시스템 먼저:** 색, 글꼴(크기·굵기·줄 간격), 간격, 모서리 둥글기, 그림자 값을 Tailwind 테마 토큰으로 정의합니다 (`src/shared/styles/index.css`의 `@theme`).
2. **공용 컴포넌트:** 버튼, 입력창, 카드처럼 여러 화면에 나오는 것을 `src/shared/ui`에 만듭니다.
3. **화면 구현:** 1, 2에서 만든 토큰과 컴포넌트를 조합해서 만듭니다.

화면 구현 중에 디자인 시스템에 없는 값이 필요하면, 임의 값을 쓰지 말고 토큰을 추가할지 먼저 확인합니다.
